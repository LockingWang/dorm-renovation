# 宿舍整理與裝潢評估專案

這個專案用來系統性地評估宿舍整理與裝潢的**成本**與**選擇**，避免衝動購物、超出預算，或買了不合用的東西。

## 檔案結構

| 檔案 | 用途 |
|------|------|
| `01-需求盤點.md` | 記錄現況、問題點、需求與限制條件（先填這份！） |
| `02-預算表.csv` | 各項目的預算規劃與實際花費追蹤，可用 Excel 開啟 |
| `03-選項比較.md` | 重大採購的決策矩陣（例如：床墊 A vs B vs C） |
| `04-採購清單.csv` | 完整購物清單，含優先級、狀態追蹤 |
| `05-時程規劃.md` | 整理與裝潢的執行順序與時程 |
| `06-現場勘查紀錄.md` | 2026-08-09 現場勘查的各空間尺寸、狀況與待辦事項 |
| `07-廠商聯絡.md` | 裝修/採購廠商的聯絡方式、洽談紀錄與比價（名片照片在 `photos/名片/`） |
| `index.html` | **一頁式網站**：各區域的照片、規格與需求總覽（雙擊直接用瀏覽器開啟） |
| `aircon.html` | **冷氣專頁**：師傅聯絡卡、溝通時間軸與方案比價（由 index 導覽列「❄️ 冷氣溝通」進入） |
| `moving.html` | **搬家專頁**：搬家公司聯絡卡、待辦、溝通時間軸與估價追蹤（導覽列「🚚 搬家紀錄」） |
| `photos/before/` | 改裝前照片（18 張，依區域命名） |
| `photos/after/` | 改裝後照片放這裡；與 before 同檔名即可在網站自動顯示前後對比滑桿 |

## 建議使用流程

1. **先盤點**：填寫 `01-需求盤點.md`，搞清楚「為什麼要買/改」，不要直接跳到買東西。
2. **訂預算上限**：在 `02-預算表.csv` 最上方訂總預算，再分配到各分類。
3. **比較選項**：金額較大的項目（通常 > NT$2,000）先在 `03-選項比較.md` 用決策矩陣比過再買。
4. **列清單、標優先級**：`04-採購清單.csv` 中標 P1（必要）/ P2（重要）/ P3（想要），預算不夠先砍 P3。
5. **排時程**：`05-時程規劃.md` 安排「先整理丟棄 → 再收納 → 最後裝飾」的順序。

## 核心原則

- **先減後加**：先丟掉/處理不需要的東西，再決定要買什麼收納或家具。
- **量了再買**：所有家具、收納用品購買前，先量好尺寸記在採購清單的「尺寸限制」欄。
- **宿舍限制優先**：確認宿舍規定（能否釘牆、用電上限、退宿時要否復原），寫進需求盤點的限制條件。
- **可帶走性**：宿舍是暫時的，優先選搬家時帶得走或容易轉賣的東西。
